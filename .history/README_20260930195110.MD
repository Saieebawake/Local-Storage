# 🌮 Local Appetizers

A simple **Local Storage-based checklist application** built using **HTML, CSS, and JavaScript**.

The project allows users to add items to a list, mark them as completed, and keep their data saved in the browser using **Local Storage**. Even after refreshing the page, the saved items remain available.

## ✨ Features

- ➕ Add new items to the list
- ✅ Mark items as completed
- 💾 Save items using Browser Local Storage
- 🔄 Data persists after page refresh
- 📋 Dynamically generate list items using JavaScript
- 🎨 Simple and responsive interface

## 🛠️ Technologies Used

## ⚙️ How It Works

1. Enter an item in the input field.
2. Click **+ Add Item**.
3. The item is added to the list.
4. The item is stored in Local Storage.
5. Click the checkbox to mark an item as completed.
6. The updated state is saved automatically.
7. Refreshing the page loads the saved items again from Local Storage.

## 💾 Local Storage

The project stores the checklist data in the browser using the key:

```javascript
localStorage.setItem('items', JSON.stringify(items));
```

When the page loads, the stored data is retrieved using:

```javascript
JSON.parse(localStorage.getItem('items')) || [];
```

This allows the application to preserve the user's list even after refreshing the webpage.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start adding items to the list.

No backend or database is required.
